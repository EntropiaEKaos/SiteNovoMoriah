# Pousada Moriah — Site + CMS

Base inicial do novo site da Pousada Moriah em Praia Grande.

## Stack
- Next.js 15 + React 19 + TypeScript
- Framer Motion
- Preparado para Vercel
- Direção visual: branco, preto e amarelo
- Área pública + /admin

## Desenvolvimento
```bash
npm install
npm run dev
```

## Roadmap CMS
Autenticação segura, PostgreSQL, mídia, páginas, hospedagens, reservas, promoções, SEO, menus, contatos e configurações globais.
